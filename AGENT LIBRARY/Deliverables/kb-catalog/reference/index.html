Four different ways to pick skills

These are not style variants. Each changes how you browse and how you select.

Browse + cart · click Add

A — Package builder

Left: category browse. Right: your package grows as you click Add. No checkboxes in the list. Download only what’s in the cart.

Like an app store / shopping cart

Persona first · then refine

B — Persona starter

Step 1: pick AE / Support / CSM / Full library. Step 2: see a recommended set already selected. Toggle off what you don’t want.

Like Salesforce “choose your role” setup

Search-first · no section scroll

C — Command search

Big search box is the UI. Type “renewal” or “case”. Results appear. Click a result to select. Categories are filter chips only — no long accordion.

Like Spotlight / Cmd+K

Move left → right

D — Dual list transfer

Available skills on the left. Selected package on the right. Move with buttons. Classic enterprise admin pattern.

Like Salesforce permission-set / dual-listbox
