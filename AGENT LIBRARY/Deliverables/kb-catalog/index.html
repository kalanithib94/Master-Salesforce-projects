          After download — what to do next
          Exact install steps + what gets added to your org
        
        
      
      

        
    
          
  1. Unzip the download package.
    2. 
          
  2. Prerequisites: GPTfy installed; Salesforce CLI (sf) with a default org in VS Code/CLI, or Workbench logged into the target org.
    3. 
          
  3. Org values: enter Mapping Id, Connection Id, Agent Name in the download dialog (Ids go into the install scripts). CLI org alias is optional — leave blank to deploy to the default connected org.
    4. 
          
  4. Fastest path (CLI / VS Code): unzip, then run install.ps1 (Windows) or install.sh (Mac/Linux). It uses your default org unless you pass an alias.
    5. 
          
  5. Workbench path: login to the target org in Workbench → Migration → Deploy (Apex package) → Utilities → Apex Execute (paste each install script). No CLI alias needed.
    6. 
          
  6. Manual CLI — Deploy Apex once:
            
    sf project deploy start --manifest package.xml
            
    (add --target-org <alias> only if not using the default org)
          
    7. 
          
  7. Manual CLI — Register skills (creates skill prompts and links them to your agent):
            
    Single skill: sf apex run --file seed.apex
            
    Multi-skill: run once per script under skills/*/seed.apex.
    8. 
          
  8. System prompt: the package always includes a composed sample-system-prompt.txt for the skills you selected. Turn on Update agent system prompt in the download dialog if you want install to overwrite the agent field automatically (replaces existing prompt).
    9. 
          
  9. Optional manual: paste sample-system-prompt.txt into the agent in GPTfy if you left the toggle off.
    10.
